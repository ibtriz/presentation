Build de Skills — QA Pleno (merge das duas vagas)
1. Fundamentos de Qualidade e Teste

o básico que um pleno já deveria dominar sem pensar muito.

Levantamento e análise de requisitos

Escrita e modelagem de cenários e casos de teste

Escrita de cenários em Gherkin / BDD

Elaboração de plano e estratégia de testes

Criação e manutenção de RTF (roteiro de testes funcionais)

Planejamento e execução de:

testes funcionais

testes regressivos

testes de integração

testes exploratórios

Gestão de bugs / bug tracking

Preparação e gerenciamento de massa de dados para testes

2. Automação de Testes

parte mais “engenharia”.

Desenvolvimento e manutenção de testes automatizados

Automação em diferentes camadas da pirâmide:

testes de API

testes de serviço

testes UI

testes E2E

Ferramentas comuns:

Selenium

Appium

Cypress

Robot Framework

Cucumber

RestAssured

Pact (contract test)

3. Pirâmide de Testes e Estratégias Avançadas

o que diferencia um QA pleno de alguém só executor.

Domínio da Pirâmide de Testes

unit

integração / serviço

E2E

Técnicas avançadas:

Testes de mutação

Contract testing

Continuous testing

Definição da estratégia de testes para cada camada

4. Testes de API e Integração

especialmente importante em arquitetura moderna.

Testes de API REST

Automação de testes de serviços

Ferramentas:

Postman

Insomnia

SoapUI

5. Testes Mobile

bem relevante no teu contexto atual.

Testes em Android e iOS

Automação mobile com Appium

Testes funcionais e integração mobile

(sim, isso casa perfeitamente com o teu time atual)

6. Testes Não Funcionais

muita vaga pleno pede isso.

Performance / carga / stress

Segurança

Acessibilidade

Ferramentas como:

JMeter

7. CI/CD e Continuous Testing

QA pleno participa da esteira, não só roda teste manual.

Configuração de stages de teste em pipelines

Integração de testes automatizados em CI/CD

Ferramentas comuns:

GitLab CI

GitHub Actions

Jenkins

AWS CodePipeline

Análise de logs

Troubleshooting em produção

Monitoramento de aplicações

11. Métricas de Qualidade

Defect Escape Rate

Análise de dados para melhoria contínua

Promoção da cultura de qualidade

Comunicação clara sobre bugs e riscos
